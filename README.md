# منصة تسليم رموز الإنجاز

## 1) فعّل قواعد الحماية في Firebase
افتح مشروعك في console.firebase.google.com ← Firestore Database ← تبويب **Rules**، والصق محتوى ملف `firestore.rules` كامل مكان الموجود، ثم اضغط **Publish**.

## 2) أنشئ حساب المعلم (إذا لم تكن سويته)
Authentication ← Users ← Add user ← اكتب بريد وكلمة سر. هذا هو دخولك الوحيد للوحة التحكم (`teacher.html`).

## 3) ارفع الملفات على GitHub Pages
1. أنشئ مستودع (Repository) جديد على GitHub.
2. ارفع كل الملفات الأربعة: `index.html`، `teacher.html`، `common.js`، وهذا الملف.
3. من إعدادات المستودع (Settings) ← Pages ← فعّل النشر من الفرع الرئيسي (main) والمجلد الجذر (/root).
4. بعد دقيقة أو دقيقتين، رابط الموقع يصير:
   `https://اسم_حسابك.github.io/اسم_المستودع/`
   - صفحة الطالب: نفس الرابط (`index.html`)
   - صفحة المعلم: أضف `teacher.html` في آخر الرابط

## الاستخدام
- **الطالب** يفتح رابط الموقع، يكتب اسمه وفصله ورقمه، يلصق رمز الإنجاز، ويضغط إرسال.
- **أنت (المعلم)** تفتح `teacher.html`، تسجّل دخولك، وتشوف كل الفصول والطلاب وجلساتهم وتقدمهم.

## ملاحظات
- الرمز القديم (بدون رقم طالب وبدون أبواب متقنة) يُقرأ بشكل طبيعي، ولن يظهر له رقم طالب ولا أبواب متقنة — وهذا متوقع.
- كل طالب يُعرّف داخليًا بالفصل + رقم الطالب (إن وجد في الرمز)، أو بالفصل + الاسم لو الرمز قديم.
- لو غيّرت كلمة سر حساب المعلم لاحقًا، فقط عدّلها من نفس صفحة Authentication في Firebase — لا حاجة لتعديل أي ملف.
